# WatchWise Compare

Fake Rolay Pop price comparison page for a harmless prank.

## GitHub Pages

Use this structure at the root of the `marsweiss.github.io` repository:

```text
index.html
preview.png
favicon.svg
reviews/rolay-pop/index.html
```

Then enable Pages:

```text
Settings -> Pages -> Deploy from a branch -> main -> / root
```

Final link:

```text
https://marsweiss.github.io/reviews/rolay-pop/
```

## Vercel

Import the same GitHub repository into Vercel. If your Vercel URL is different, update the Open Graph URLs in:

```text
reviews/rolay-pop/index.html
```
